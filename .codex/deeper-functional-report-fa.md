# بررسی عمیق‌تر قابلیت‌های پروژه‌های مرجع

این گزارش حاصل خواندن کد سه پروژه و تطبیق با نسخهٔ فعلی Roadeep است. گزارش قبلی بیش از حد روی قابلیت‌های قابل پیاده‌سازی سریع، ظاهر کاراکتر و مشاهدهٔ فعالیت تمرکز داشت؛ جریان‌های مدیریت اسناد، اجرای ایجنت و کنترل جلسه به اندازهٔ کافی بررسی نشده بودند.

این نوبت فقط بررسی انجام شد؛ کد محصول تغییر نکرد و برنامه‌های مرجع اجرا یا نصب نشدند. وجود تست در پروژه‌های مرجع به معنای اجرای موفق آن‌ها در این بررسی نیست. موارد وابسته به سرویس بیرونی و قسمت‌های نمایشی جدا مشخص شده‌اند.

## پروژه‌ها

- **A / OpenDots-main.zip:** فضای اسناد، متخصص‌های هوش مصنوعی و گفت‌وگوی متصل به سند؛ React/Hono و CopilotKit.
- **B / open-dots-main.zip:** محیط چت با عملیات دارای تأیید، فایل‌های محلی و آداپتورهای کامپیوتر؛ Next/FastAPI.
- **C / dotpals-main.zip:** پایش و هماهنگی ابزارهای کدنویسی، تحلیل پیشرفت و کنترل برخی جلسه‌ها.

## اولویت استفاده در Roadeep

1. **تکمیل فعالیت کدنویسی:** plan زنده، retry، ریسک قابل توضیح و چک‌لیست پایان کار. به پنل موجود متصل می‌شود و فوراً فهم کار ایجنت را بهتر می‌کند. ابتدا تحلیل محلی و دادهٔ حداقلی؛ checker بیرونی لازم نیست.
2. **حفاظت فایل مشترک و کنترل جلسه:** محافظ اختیاری قبل از ویرایش Claude، سپس آداپتور OpenCode و به تدریج سایر harnessها. هر ابزار باید فقط قابلیت‌هایی را نشان دهد که واقعاً پشتیبانی می‌کند. تغییر hook/config نیازمند merge و مسیر نصب موجود است.
3. **اسناد متصل به ایجنت:** یادداشت‌ها را به صفحه/زیرصفحه با جست‌وجو، گفت‌وگوی کنار سند، پیشنهاد قابل بازبینی و ذخیرهٔ دارای revision گسترش دهیم. نیازمند مدل داده و مجوز فضای کاری است؛ افزودن چند دکمه کافی نیست.
4. **اجرای زمان‌بندی‌شدهٔ ایجنت:** از Planner برای انتخاب زمان استفاده شود ولی job/run/result و بازیابی مستقل تعریف شوند. مصرف API و عملیات حساس باید قابل کنترل باشند؛ lease جای idempotency سرویس بیرونی را نمی‌گیرد.
5. **ثبت یکپارچهٔ عملیات و فایل‌های پروژه:** استفاده از سیاست MCP فعلی، audit ماندگار با حذف اسرار و دسترسی محدود به ریشهٔ انتخاب‌شدهٔ کاربر.
6. **صوت، Slack و کامپیوتر ایزوله:** پس از نیاز روشن محصول؛ وابستگی سرویس، منابع اجرایی و چرخهٔ اتصال دارند. منطق کنترل مجوز و تحویل کنترل قابل استفاده است، اما کپی سورس به تنهایی قابلیت آماده ایجاد نمی‌کند.
