# صدا و رایانهٔ ایجنت — نتیجهٔ پیاده‌سازی

به چت Roadeep دو کنترل «صدا» و «رایانه» و به تنظیمات بخش «صدا و رایانه» اضافه شد.

## امکانات

- مکالمهٔ صوتی WebRTC با OpenAI Realtime، انتخاب مدل و صدا، شروع/پایان، قطع میکروفون و متن زنده. درخواست‌های کاری از همان مدل متنی، تاریخچه و تأیید ابزارهای چت عبور می‌کنند.
- کلید صدا در Windows Credential Manager ذخیره می‌شود؛ صدا و بخش محدود اخیر گفت‌وگو به سرویس ارسال می‌شوند و مصرف API دارند. کلید به رابط برگردانده نمی‌شود.
- برای هر ایجنت، محیط Docker جدا با مرورگر Playwright، فایل‌های محیط کار و ترمینال Linux/Node. شروع، توقف موقت، ادامه، خاموش‌کردن، بازنشانی و گرفتن/بازگرداندن کنترل دستی.
- عملیات اجرایی ایجنت نیازمند تأیید چت است. هنگام کنترل دستی، ابزارهای ایجنت اجرا نمی‌شوند. کانتینر به فایل‌ها و سوکت Docker میزبان دسترسی ندارد و مرورگر فقط از مسیر محدود و بررسی‌شدهٔ HTTP عمومی استفاده می‌کند.
- فایل‌های محیط موقت‌اند و با خاموش‌کردن یا بازنشانی از بین می‌روند. ترمینال دسترسی مستقیم شبکه ندارد. محیط، ماشین مجازی اختصاصی نیست؛ مرز ایزوله‌سازی Docker است.

## راه‌اندازی

1. در تنظیمات ← صدا و رایانه، کلید OpenAI خود را وارد کنید و مدل/صدا را ذخیره کنید.
2. Docker Desktop با کانتینرهای Linux را اجرا کنید. دستور ساخت تصویر را از همین صفحه در PowerShell اجرا کنید؛ مسیر بستهٔ نصب در دستور درج می‌شود. این مرحله تصویر و وابستگی‌ها را دانلود می‌کند.
3. در چت، صدا را شروع کنید یا رایانهٔ ایجنت انتخاب‌شده را روشن کنید. استفاده از ابزارها در چت باید فعال باشد.

برنامه کلید، Docker یا تصویر را خودکار تهیه نمی‌کند. برای این بررسی، سرویس صوتی پولی، میکروفون واقعی و کانتینر زنده اجرا نشدند: کلید ارائه نشده و Docker daemon در دسترس نبود. وضعیت تنظیم‌شده به معنی تأیید اتصال سرویس نیست.

## اعتبارسنجی نهایی

- TypeScript: ۲۸۷ تست موفق در ۳۵ فایل؛ بررسی نوع و Vite production build موفق.
- Rust: ۴۱۷ تست برنامه و ۲۰ تست MCP موفق؛ ۴ تست از پیش نادیده‌گرفته‌شده؛ بدون خطا.
- محیط رایانه: ۶ تست مسیر، فایل، symlink و محدودیت پردازش موفق؛ بررسی syntax فایل‌های Node موفق.
- بسته‌بندی: ۲۰ تست موفق. ساخت Windows release و NSIS موفق؛ نصب با `/S /UPDATE` کد خروج ۰ داد.
- مرورگر محلی: چت واقعی، تنظیمات، حالت‌های پیش‌نمایش صدا/رایانه، تب‌های کیبورد و بازگشت فوکوس با Escape بررسی شدند. تصاویر پیش‌نمایش اتصال واقعی را ادعا نمی‌کنند.

جزئیات فنی و محدودیت‌ها: `windows/src/voice/README.md` و `windows/computer-runtime/README.md`.
